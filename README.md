# 双城图志 · 公共地点资料

伦敦与福州的公共地点与活动资料（JSON），由本机内容后台自动同步到这里，供《双城图志》电脑版和安卓版在线更新。

App 内“Codex 内容后台”地址：

    https://mikhailxiaomaikou.github.io/twin-city-atlas-content/content.json

仅包含公开来源的公共资料，不含任何个人记录。

## 网页版

    https://mikhailxiaomaikou.github.io/twin-city-atlas-content/

同一份 `content.json` 的浏览页面：伦敦 / 福州 / 双城对照地图，地点按区域路牌分组，活动按当地日期排成时刻表（可导出 .ics 加入日历），并列出每条资料的来源与核验状态。

- 纯静态页面，无构建步骤：`index.html`、`assets/`（样式、脚本、字体）、`vendor/`（Leaflet 与聚合插件）。
- 不依赖外部 CDN；只有底图瓦片来自 CARTO（© OpenStreetMap contributors © CARTO）。底图加载失败时，点位与列表仍可使用。
- `assets/planner.js` 是攻略规划的纯函数模块（开放时间语法、日出日落、伦敦当地时间、交通估算、附近推荐、行程规划），浏览器和 Node 都能用；`node tests/planner.test.js` 运行检查。
- 链接可直接定位：`#london`、`#fuzhou`、`#both`、`#guide`（伦敦攻略）、`#events`、`#sources`，或某个地点的 id（如 `#london-british-museum`、`#london-tower-of-london`）。
- 本地预览：在仓库根目录运行 `python3 -m http.server`，打开 http://localhost:8000/ 。

## 资料约定

- 坐标系 WGS84。地图点多为建筑、园区或邮编中心的概略位置，不代表入口；每条说明里写明坐标来源与精度。
- 时间字段为 UTC 毫秒；活动另带 `timeZone`（伦敦为 `Europe/London`）。开放时间文字均注明当地时间。
- `priceMinor` 以便士计；`0` 为免费，`null` 为分档或未确认（详见标题、系列或来源说明）。
- `sources[]` 按 URL 与地点、活动对应；`validUntil` 过期后表示该条活动资料已结束。

- **此刻 · 附近能去**：点“用我的位置”（或在地图上点选、选常用出发点），按伦敦当前时间列出现在开着、走得到、这个时段合适的地方，并说明理由（步行几分钟、几点关门、日落前适合登高、正是饭点……）。定位只在页面内使用，不上传、不保存。

### 资料：`guide/london.json`

- 只供网页版使用，**不在应用内容地址里**：`content.json` 的结构与内容未改动，电脑版与安卓版的同步不受影响；本机内容后台同步 `content.json` 时也不会覆盖它。
- `places`：182 处新增地点；`overlays`：为 `content.json` 中 45 处伦敦地点按 id 补充的游玩信息（开放时间按原文整理、建议时长、推荐度、交通、贴士）；`routes`：现成路线；`tips`：伦敦须知。
- 每条地点字段：中英文名、类别与标签、坐标、地址、最近车站、`hours`（OpenStreetMap opening_hours 子集：`Mo-Fr 10:00-17:00; Sa 09:00-18:00`、`Fr,Sa 11:00-01:00`、`Mo-Su 07:00-dusk`、`24/7`）、`seasonal`（按月日覆盖）、`closed`（闭馆日）、`dates`（只在某段日期存在）、`lastEntry`（关门前多少分钟停止入场）、`slots`（固定开场时间，如演出、卫兵换岗）、`visitMin`、`price`（便士）、`indoor`、`best`、`score`（1–5）、简介、贴士、预约说明、来源与核验说明。
- 核验情况：资料于 2026-10-07 整理，通过搜索引擎读取各官方页面的内容核对开放时间与票价（官网多数无法直接打开，以搜索结果为准）。本轮联网检索有配额上限，**73 处标“待核实”**（开放时间或票价依据此前的公开资料整理、未能联网复核），在列表、地点页、附近推荐与行程中都有标记；全天开放的公共空间（广场、桥、街区）未标。坐标多为按公开资料估计的建筑概略位置，误差约 50–150 m。出发前请仍以官网为准。
- 交通时间是估算：步行按直线距离 × 1.25、约 4.6 km/h；超过约 20 分钟时按地铁/公交门到门估算。实际以 Citymapper / Google 地图为准。
